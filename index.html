Repository setup

  1. Install Node.js 24, npm 11 and PostgreSQL 17.
  2. Clone tutor-mx-system and copy .env.example to .env.
  3. Run npm ci, npm run generate, npm run db:migrate and npm run db:seed.
  4. Start with npm run dev; verify with npm run check.
Open exact repository README

Team workflow

  1. Create or claim a tracked issue.
  2. Branch for one reviewable outcome.
  3. Test locally and attach evidence.
  4. Open a pull request; another member reviews it.
  5. The integration lead merges approved work.

AI-assisted work must identify tool, model and purpose. The team remains responsible for verification.

System boundary

Browser client → handwritten Express API → Prisma → Neon PostgreSQL.

The browser must not connect directly to Neon or receive service credentials. Authentication must use an established provider or library.

Publish team updates

Export after editing, replace data/site-data.json, then commit and push. Import another member’s JSON to continue their work.
